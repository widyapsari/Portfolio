# Portfolio
A collection of my projects in data analytics and NLP

## NLP and Text Mining 
| Project | Tools | Description
| -- | -- | -- | 
| [Named Entity Recognition](https://github.com/widyapsari/ML_Named_Entity_Recognition) | Python, Scikit-learn, BiLSTM  | Evaluated Logistic Regression, SVM, Naive Bayes, and BiLSTM approaches for NER on the CoNLL-2003 dataset, examining the impact of feature engineering, ablation, and hyperparameter tuning.|
|[Social Media Text Mining](https://github.com/widyapsari/Language_as_Data) | Python, Pandas, NLTK, Matplotlib | Collected and preprocessed Indonesian and English tweets using the Twitter API. Applied text mining techniques including keyword-based categorization, word analysis, statistical comparison, and inter-annotator analysis to examine linguistic patterns across the two languages.
| [Negation Cue Detection](https://github.com/widyapsari/AppliedTextMining) | Python, Pandas, Scikit-learn, MLP | Compared SVM, Logistic Regression, and neural network models for negation cue detection using lexical, syntactic, and structural features on the SEM 2012 Shared Task dataset, examining the impact of feature selection and training data quality.
| [Semantic Role Labelling Model Evaluation](https://github.com/widyapsari/Adv_NLP_ChallengingSRL) | Python, AllenNLP, BERT, BiLSTM, CheckList | Compared BERT- and BiLSTM-based SRL models across seven capability tests, examining their performance on varied syntactic and lexical-semantic structures. BERT demonstrated stronger argument prediction performance.
| [Hate Speech Detection](https://github.com/widyapsari/MA-Thesis) | Python, Pandas, NLTK, Scikit-learn | Compared SVM and BERT for abusive language detection, evaluating their robustness against seven word-obfuscation techniques and their combination. Evaluated performance using precision, recall, and F1 score, finding that SVM was generally more affected by obfuscation while BERT showed variable performance across the obfuscated datasets.
